How it works

  1. 1

    Connect your agent

    Claude Code, Codex, Cursor or any MCP client. claude.ai and ChatGPT connect as remote connectors over OAuth.

    claude mcp add --transport http 9artifacts https://art.you.dev/mcp
  2. 2

    Ask it to publish

    “Make a dashboard of this CSV and publish it to 9artifacts.” It reads your design.md first, so the result looks like yours.

    → https://art.you.dev/a/k3x7…
  3. 3

    Review, comment, share

    Select text and leave a comment. Your agent reads it, publishes v2 and resolves it; your open tab reloads by itself. Share an expiring link when it’s ready.

Everything an artifact needs, nothing it doesn’t

Private by default

Everything sits behind your passkey. Public links always expire (1 hour to 30 days), can be revoked, and can have a password and a view limit.

Made for agents

A built-in MCP server, a CLI and an installable skill. Agents get back a private URL to hand you, and only share when you ask.

A review loop

Comments go back to the agent over MCP. Every version is kept, and any old one can be restored.

Feels like Claude’s viewer

Full-bleed sandboxed viewer, version history and live reload, on a separate content origin for isolation.

Your style, everywhere

Agents read your design.md before writing. The app itself is themeable, and your AI can restyle it.

Tiny and free to run

Happy on a 1 vCPU / 512 MB box or a Raspberry Pi, with automatic HTTPS. No server? The Workers edition runs on the free plan.

Install

Point two DNS records at your server (one for the app, one for artifact content), then:

curl -fsSL https://raw.githubusercontent.com/dinhkarate/9artifacts/main/install.sh | sudo sh -s -- --domain art.example.com --content-domain art-content.example.com --email you@example.com

Installs the binary and a hardened systemd service, and fetches Let’s Encrypt certificates itself. Open the first-run link it prints, set a password and add a passkey.

docker run -d --name 9artifacts -p 8080:8080 -v 9artifacts:/data -e NINEARTIFACTS_URL=http://localhost:8080 ghcr.io/dinhkarate/9artifacts

docker logs 9artifacts prints the first-run link. Behind nginx, Caddy, a Cloudflare Tunnel or Tailscale? See the deploy guide.

No server at all: deploy the Workers edition (D1 + R2) on the free plan.

Set the SETUP_TOKEN secret when asked, open your workers.dev URL and add a passkey. Details.

Built for documents you wouldn’t paste into a pastebin

  • Sandboxed artifacts. Every artifact runs with CSP: sandbox on a separate origin, with no cookies and no API access.
  • Passkeys. WebAuthn sign-in, lockouts, __Host- session cookies and CSRF checks.
  • Hashed, revocable tokens. Agents can publish but cannot mint tokens or change login settings.
  • Links that end. 144-bit share tokens pinned to a version; expired or revoked links return 410.
